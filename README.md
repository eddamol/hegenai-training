# HEGenAI Training

Landing page for the pilot and training on GenAI in assessment and feedback
for higher education educators (MSc thesis, DTU Compute, within the Erasmus+
project HEGenAI). Plain HTML and CSS, no JavaScript, no third-party requests,
no data collected. Hosted on GitHub Pages; all links are relative.

## Files

- `index.html`: landing page
- `privacy.html`: privacy notice
- `style.css`: shared styling
- `assets/`: `logo-w.svg`, `logo-b.svg`, `favicon.svg` (placeholders; replace with the real files under the same names)
- `.nojekyll`: switches off Jekyll on GitHub Pages

## Preview

Open `index.html` in a browser. No build step.
